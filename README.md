# Smart Plant Monitoring and Automatic Irrigation System Using ESP32

An IoT-based smart irrigation system developed using ESP32, Soil Moisture Sensor, DHT11, Ultrasonic Sensor, OLED Display, Relay Module, Water Pump, and Blynk IoT Platform.

## Features
- Automatic Plant Watering
- Soil Moisture Monitoring
- Temperature & Humidity Monitoring
- Water Tank Level Detection
- OLED Display
- Blynk Dashboard Integration
